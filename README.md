# 🛡️ Network Security Labs | De la Teoría a la Práctica (Blue Team / SOC)

¡Bienvenido/a a este repositorio! Este espacio está diseñado como una guía práctica orientada a quienes están iniciando su camino en la ciberseguridad, con un enfoque particular en roles defensivos (**Blue Team** y **SOC Analyst**).

Muchas veces, al estudiar ciberseguridad, nos encontramos con explicaciones teóricas extensas sobre ataques de red, pero falta esa parte técnica y manual que permite visualizar **qué ocurre realmente a nivel de tráfico y de consola**. El objetivo de este proyecto es acortar esa brecha ofreciendo laboratorios prácticos paso a paso en entornos controlados.

---

## 🎯 Objetivo del Repositorio

* **Aprender haciendo:** Proporcionar laboratorios prácticos en formato PDF para pasar de la teoría a la ejecución visual.
* **Perspectiva defensiva:** Entender la mecánica interna de los ataques de red (ARP Spoofing, DNS Poisoning, MITM, etc.) para saber cómo detectar, analizar y mitigar estas amenazas en un SOC.
* **Accesibilidad:** Crear guías claras y guiadas que cualquier principiante pueda replicar en sus propias máquinas virtuales o laboratorios locales.
